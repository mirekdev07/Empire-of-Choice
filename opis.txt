[1] STOS TECHNOLOGICZNY (THE STACK)
-----------------------------------
Podejście "Hybrid Local": Baza w kontenerze, aplikacja lokalnie (dla szybkości).

1. Infrastruktura: Docker & Docker Compose (Baza danych).
2. Runtime: Node.js (uruchamiany lokalnie na hoście).
3. Język: TypeScript.
4. Framework: Next.js 14+ (App Router).
5. Baza Danych: PostgreSQL (w kontenerze Docker).
6. GUI Bazy: PgAdmin4 (w kontenerze Docker).
7. ORM: Prisma.
8. Auth: NextAuth.js (v5) - idealny do testów lokalnych lub Clerk.
9. UI: Tailwind CSS + Shadcn/UI.

[2] FAZA 0: KONFIGURACJA ŚRODOWISKA (DOCKER)
-----------------------------------
Cel: Postawienie bazy danych bez zaśmiecania systemu operacyjnego.

Krok 0.1: Przygotowanie pliku docker-compose.yml
- [ ] Stwórz pusty folder projektu `my-tycoon`.
- [ ] Stwórz w nim plik `docker-compose.yml` o treści:

version: '3.8'
services:
  db:
    image: postgres:15-alpine
    container_name: tycoon_db
    restart: always
    environment:
      POSTGRES_USER: devuser
      POSTGRES_PASSWORD: devpassword
      POSTGRES_DB: tycoondb
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
  pgadmin:
    image: dpage/pgadmin4
    container_name: tycoon_pgadmin
    environment:
      PGADMIN_DEFAULT_EMAIL: admin@admin.com
      PGADMIN_DEFAULT_PASSWORD: admin
    ports:
      - "5050:80"
    depends_on:
      - db
volumes:
  postgres_data:

Krok 0.2: Uruchomienie infrastruktury
- [ ] W terminalu: `docker-compose up -d`
- [ ] Sprawdź czy kontenery działają: `docker ps`
- [ ] (Opcjonalnie) Wejdź na http://localhost:5050 (PgAdmin), zaloguj się i sprawdź, czy możesz połączyć się z serwerem "db".

Krok 1.3: Modelowanie Danych (schema.prisma)
- [ ] Wklej do `prisma/schema.prisma`:

model User {
  id            String   @id @default(cuid())
  email         String   @unique
  // Logika Gry
  chosenPath    String?  // "INDUSTRIAL", "MEDIA", "FINANCE"
  money         Float    @default(1000) // Kapitał startowy
  createdAt     DateTime @default(now())
  lastSaveTime  DateTime @default(now())
  
  buildings     Building[]
}

model Building {
  id         String @id @default(cuid())
  userId     String
  buildingId String // ID z pliku config np. "mine_v1"
  count      Int    @default(0)
  user       User   @relation(fields: [userId], references: [id])
  @@unique([userId, buildingId])
}

- [ ] Wykonaj pierwszą migrację (to utworzy tabele w kontenerze):
      `npx prisma migrate dev --name init`
